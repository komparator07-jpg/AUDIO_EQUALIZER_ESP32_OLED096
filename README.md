# AUDIO_EQUALIZER_ESP32_OLED096
Эквалайзер на ESP32 и OLED 0,96.
Аудио информация транслируется скриптом на piton с компа на ESP32 в виде информации для Serial порта. 7 режимов эквалайзера.
Когда теряется связь со скриптом на компе или нет аудиоинформации более 60 сек, переходит на автономный режим с визуализацией своей внутренней "синтезированной" музыки.
